# Heft

A personal, offline-first workout tracker in the spirit of Hevy, without the social features.

- Start an empty workout or a routine; add exercises from the library or from your routines
- ~800 exercises (barbell, dumbbell, machine, cable, Smith machine, kettlebell, band, cardio) with start/end pictures
- Rename any exercise, or create a gym/brand variant of a machine that keeps its own history
- Rest timer, PRs, workout duration and calorie estimates
- Progress charts, a front/back muscle map, history calendar, body measurements
- All data stays on your device (IndexedDB); export/import a JSON backup from Settings

Install: open the site in Safari (iPhone) or Chrome (Android) and choose **Add to Home Screen**.

Develop: `npm install`, `npm run dev` (port 5180), `npm test`, `npm run build`. See `ARCHITECTURE.md`.

Exercise images and instructions: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).

Muscle map body artwork: [MuscleMap](https://github.com/melihcolpan/MuscleMap) by Melih Colpan (MIT, see `THIRD_PARTY_NOTICES.md`).
